# 方案评审：难点、卡点与对策

> 2026-09-20。评审对象：[laundry-two-plans-brief.md](laundry-two-plans-brief.md)（方案 A / B 与加速版）、[laundry-sorting-brain-plan.md](laundry-sorting-brain-plan.md)、[laundry-fold-hang-plan.md](laundry-fold-hang-plan.md)、[dyna-parity-fast-track.md](dyna-parity-fast-track.md)、[capture-devices-design.md](capture-devices-design.md) §1.1（D1-H）、[dyna-replica-plan.md](dyna-replica-plan.md) §12。评审方式：逐份重读，按"物理上做不做得出 → 流程上接不接得上 → 数字站不站得住 → 组织上来不来得及"四个角度找问题。**本文的判断是我方工程推断 ⚠️，没有实测支撑；涉及洗衣机远程启动、商用机接口、安全标准的说法来自一般经验，未核查，均列入第 1–4 周核实项。** 对策已回写到各方案，对应位置见 §6。

## 0. 结论先说

1. **最大的卡点不在模型，在本体和现场。** 排在前面的五项是：自研本体的可用率、位控手臂做刚性接触（开门、台面捏布、筒内取衣）、洗烘机器到底能不能被程序启动、湿衣缠绕取出、试点场地与责任归属。这五项没有一项能靠多采数据或换基座解决。
2. **原方案里有三处设计缺口**（不是风险，是漏了）：
   - "不可烘"只打了标记，但衣物一进洗衣机身份就丢了，洗完无法再把它挑出来 → 改为**洗前就分到单独的筐**（§2 S-1）。
   - "用夹持力判断是否只抓了一件"站不住，夹持力不反映件数 → 改为**夹爪开度 + 提起重量（关节电流）+ 展示位视觉**三者合判（S-2）。
   - "筒内已取空"没有检查手段，漏一只袜子就是订单混淆（零容忍项）→ 加**筐体称重对账 + 腕部相机扫筒**（W-4）。
3. **原方案里有三个数字偏乐观**：每个子技能 ≤10 h 是 Dyna 在自家预训练基座上的口径，外取基座没见过我们的本体，实际可能要 2–5 倍（X-3）；3% 错分率没有人工基线做参照（S-4）；泛化探针的 60% / 30% 判据没有规定试验次数，几十次试验的置信区间有 ±12 个点（F-7）。
4. **最便宜的对策几乎都是改环境，不是改模型**：软垫台面、洗衣机垫高、门磁吸保持、固定俯视相机、筐体秤、停靠导向件、夹式晾架。合计约 $5–12k ⚠️，落在原环境件预算区间内上沿。原则写进各方案：**能用夹具和场地消掉的难度，不留给模型。**
5. **预训练路线的两个硬伤**：洗衣视频里手大半被布遮住，手姿提取的通过率可能远低于一般家务视频（P-1）；视频骨干在 Thor 上跑不到 10 Hz，自有基座的部署形态应按"站点服务器推理"设计（P-3）。
6. 四件新增拍板事项负责人已于 2026-09-20 确认（§5）；前 4 周的去风险清单见 §4。

## 2. 分方案评审

### 2.1 贯穿项（X）

| 编号 | 难点 / 卡点 | 为什么 | 对策 | 时点 |

### 2.2 交付一：分类（S）

| 编号 | 难点 / 卡点 | 对策 |
|---|---|---|
| S-1 | **设计缺口：`no_tumble_dry` 只打标记不够。** 衣物进洗衣机后身份丢失，洗完是一团湿衣，无法再识别出哪件不能烘；而交付一不含晾 | "不可烘"从标记改为**分筐维度**：洗前就分到"不可烘"筐，单独成一锅或装网袋；洗后整筐交人工晾（交付一）或交晾挂流程（交付二）。筐数因此增加，小订单会拆成很多小锅，影响洗衣机利用率——**分筐方案必须按试点洗衣房现行做法配置**（很多代洗店按订单整锅洗、只分深浅），第 1 周向现场确认 |
| S-2 | **设计缺口：夹持力判"只抓了一件"不成立** | 改为三者合判：夹爪闭合后的开度（布层厚度）、提起后的重量（关节电流差，A0 标定）、展示位视觉（轮廓是否为单件）；判为多件则放回重抓 |
| S-3 | **8,000 件不同衣物从哪来。** 计划要求第 3 周 2,000 件，但试点洗衣房第 1 个月才签 | **按公斤采购二手衣物**作为训练主力（几千件成本很低、长尾丰富、可以随意弄湿弄脏）；测试集与"新站点测试集"必须来自真实订单（内部洗衣服务 + 试点现场），避免二手衣物分布偏差 |
| S-4 | **错分率 ≤3% 没有参照。** 不知道人工是多少 | 第 1–4 周在同一测试集上测**人工基线**（洗衣房师傅按现行做法分）；验收口径改为"不劣于人工基线且高代价错分 ≤0.5%" |
| S-5 | **"易掉色""新牛仔"看不出来**，色牢度不是视觉属性 | 规则保守化：高饱和红 / 深蓝 / 深色牛仔一律进深色单独筐；不把"判断是否掉色"列为模型任务 |
| S-6 | **口袋有物看不见**，人是靠手摸 | v1 不做；服务条款约定客户自行清空；只对"明显鼓包"报注意项 |
| S-7 | 衣堆过高时一抓带起一串 | 倒袋后先摊薄：宽台面 + 限高挡板；"抖落 + 二次抓取"子技能（原有） |
| S-8 | 每次 LoRA 刷新后置信度校准漂移 | 重新校准列为发布门；校准集每月用回流难例刷新 |

### 2.3 交付一：洗与烘（W）

| 编号 | 难点 / 卡点 | 对策 |
|---|---|---|
| W-1 | **"程序走联网控制"可能不成立。** 家用智能洗衣机的远程启动通常要求每次在面板上手动开启远程模式 ⚠️；商用投币机多数没有开放接口 ⚠️ | 选型标准第 1 周定：首选带开放 / 本地接口的机型；**兜底方案是机器人按面板**——面板是刚体、位置固定，贴标记物后用解析原语按键 / 旋钮，属于最适合仿真验证的一类动作。两条路第 1 周并行验证，不等接口谈判 |
| W-2 | 放洗涤剂（倾倒液体）对位控手臂不划算 | **从机器人任务里移除**：用自动投放机型或外接自动投放泵；不行则用洗衣凝珠（抓放刚体） |
| W-3 | **湿衣缠绕取出**：脱水后衣物贴壁、互相缠绕，湿重是干重的 2–3 倍，整团拉出时受力大 | ① A0 阶段实测手臂有效负载与电流保护阈值（本体参数待补）；② 策略上小把取、分多次；"拉—抖—再抓"单列子技能；③ 电流超阈值即松手重抓，不硬拉；④ 选机型时优先大门径、筒浅、结束后自动松衣的机型；⑤ 第 2 周开始采（原有） |
| W-4 | **设计缺口：取空确认。** 筒内漏一件 = 下一个订单混入异物（零容忍） | ① 腕部相机扫筒（加腕部补光，筒内很暗）；② **筐体称重对账**：每个筐位放秤，订单干重入 = 烘后干重出（容差内），不平则报警转人工；③ 取完后点动转筒再扫一次 |
| W-5 | 订单 ↔ 机器的对应关系只存在于大脑的状态里 | 状态机持久化（断电重启可恢复）：`order_id` ↔ 筐 ↔ 机器编号 ↔ 程序 ↔ 起止时间，写入事件日志；机器门上贴编号标记物 |
| W-6 | 洗衣机高度与人形工作空间不匹配 | 机器垫高到升降腰 + 手臂的舒适区（A0 实测后定）；门开向与停靠位固定 |
| W-7 | VR 遥操作看不到筒内 | VR 画面加腕部相机画中画；筒内补光；新操作员 1–2 周爬坡期的数据单独标记，默认不进训练 |

### 2.4 交付二：叠、晾、收纳（F）

| 编号 | 难点 / 卡点 | 对策 |
|---|---|---|
| F-1 | **台面单层捏取**：薄布平铺在硬台面上，二指夹爪要贴着台面才捏得起一层，位控下就是撞台面 | **软垫台面**（泡棉底 + 高摩擦、与衣物反差大的面料）；薄型指尖；优先从台面边缘或隆起处起手；电流保护（X-2） |
| F-2 | 摊平是承重技能，但位控不能大幅甩动；大件超出臂展 | 以拖拽 + 对角拉展为主（原有）；**白名单加尺寸上限**：最大边长不超过双臂有效工作空间（A0 实测），**床单移出矩形类，归人工**；浴巾视实测而定 |
| F-3 | "关键点用语言描述、动作模型自己落点"把握低：这一档 VLA 的语言定位能力弱 | 改为默认做法：**大脑在图上给出关键点的像素坐标，叠加成可见标记后送入动作模型**（视觉提示），不另训检测器；泛化探针里与纯语言方式做对照 |
| F-4 | **穿衣架**是双臂操作里最难的一类，湿衣更粘、更重；50–80 h 数据很可能不够 | 晾挂分两批：**第一批只做夹式晾挂**（夹子固定在晾架上，机器人只需把衣物边缘送入夹口）和固定治具辅助的衣架（治具把衣架固定在已知位姿）；自由穿衣架放第二批，不进交付二验收 |
| F-5 | 洗后衣物袖子 / 裤腿内翻 | v1 内翻件进人工筐；内翻比例在试点现场统计 ⚠️，比例高再立项"翻面"子技能 |
| F-6 | 步骤成败与折叠质检全靠 VLM 判断，主观且慢 | 叠衣位加一台**固定俯视相机**：外接矩形尺寸、边缘对齐度、外露部分用几何量直接算；VLM 只判几何量覆盖不了的项 |
| F-7 | **泛化探针判据没有试验次数**，而它决定是否启动方案 B（数十万至上百万美元） | 每个条件 ≥60 次试验（60% 附近的 95% 置信区间约 ±12 个点）；判据、试验数、评测人事先书面固定；落在灰区（留出实物 50–70%）则加测到 120 次再裁决 |
| F-8 | 烘后衣物带静电、成团 | 复用交付一的单件分离原语；烘干加防静电手段由现场定 |

### 2.5 方案 B 与最快路线（P）

| 编号 | 难点 / 卡点 | 对策 |
|---|---|---|
| P-1 | **洗衣视频的手经常被布盖住**，手姿提取通过率可能远低于一般家务；"每可用小时 $6–12"是一般场景口径 | 签大单前先买 50 h 洗衣视频跑伪动作工厂，**实测通过率**再定价；通过率低于三成则洗衣场景改以同构手持器真值为主、视频只进无标签目标 |

## 3. 原则（写进各方案）

1. **能用夹具和场地消掉的难度，不留给模型。** 环境件清单：软垫台面、洗衣机垫高、门磁吸保持器、面板与门的标记物、停靠导向件、筐位秤、叠衣位固定俯视相机、腕部补光、夹式晾架与衣架治具、分拣台限高挡板。约 $5–12k ⚠️ 待询价。
2. **刚体、固定位置的动作走解析原语，不进学习策略**：开关门、按面板、停靠、放筐。学习策略只负责布。
3. **每个零容忍项都要有独立于模型的检查手段**：订单混淆 → 称重对账；夹门 → 电流保护 + 门位标记物；掉落 → 夹爪开度 + 重量监测。
4. **每个判据写明试验次数与置信区间**，决定大额投入的判据事先书面固定。
5. **验收指标对照人工基线**，不对照凭空定的百分比。
