## 1. 数据清洗→预训练数据集的衔接

核心结论先行：**没有任何一家公开完整的清洗代码，但所有公开配方都印证同一模式**——(a) 数据混合按"任务-机器人组合"做温度加权而非均匀采样；(b) 清洗以"移除/降权整个数据集或 episode"为主，帧级过滤为辅；(c) 动作空间统一 = 零填充到最大维度 + 分位数归一化（两种主流实现）；(d) 动作表征分裂为"离散 token 训练效率高"与"流匹配/扩散推理质量高"两派，且 2025 年后主流做法是**预训练用离散、后训练换连续**。

### 1.1 π0（Physical Intelligence, 2024-10）

来源：[arXiv:2410.24164](https://arxiv.org/abs/2410.24164)（全文 [html v4](https://arxiv.org/html/2410.24164v4)）

- **混合**：自采 903M 时间步（106M 单臂 + 797M 双臂），7 种机器人构型 × 68 任务；开源数据（OXE "Magic Soup" 子集 + Bridge v2 + DROID，22 种机器人）仅占混合的 **9.1%**。
- **加权（关键可抄细节）**：每个"任务-机器人组合"按 **n^0.43** 加权（n 为样本数），压制过采组合——这是数据集层的采样器职责，不是训练代码的职责。
- **清洗**：预训练容忍杂数据但要求**分层语言标签**（任务名 + ~2 秒粒度的子段标注）；后训练明确要求"consistent and fluent strategy"的精策划数据——与 Figure "8 小时精策划"同一哲学：预训练重覆盖、后训练重质量。
- **动作空间统一**：配置/动作向量**零填充到全数据集最大维度**（18 维）。
- **表征**：条件流匹配，动作块 H=50，最高 50 Hz 控制，推理 10 步积分（δ=0.1）。模型 3.3B（3B PaliGemma + 0.3B 动作专家），全量训练 700k 步。

### 1.2 π0.5（Physical Intelligence, 2025-04）

来源：[arXiv:2504.16054](https://arxiv.org/abs/2504.16054)（全文 [html v1](https://arxiv.org/html/2504.16054v1)）

- **混合**：目标域（移动操作，约 100 个家庭、~400 小时）在第一阶段训练中仅占 **2.4%**——97.6% 是非移动机器人数据（多环境静态臂 ME、实验室跨具身 CE 含 OXE、web 多模态 WD、高层子任务标注 HL、口头指令 VI）。**跨具身/跨环境迁移承担了主要泛化负担**。
- **两阶段课程（对我们最重要的结构性结论）**：预训练 280k 步用 **FAST 离散动作 token**（训练效率高）；后训练 80k 步引入**流匹配动作专家**（α=10.0）同时保留文本预测。即：离散 token 打底、连续表征收尾。
- **分层推理**：π(动作,子任务|观测,任务) = π(动作|观测,子任务)·π(子任务|观测,任务)，先预测语义子任务再出低层动作——印证我们策展第 5 阶段"任务级+子任务级双层指令"直接对应其 HL 数据轨。
- 口头指令（VI）占高层移动操作样本的 11%，人工标注被认为关键。

### 1.3 GR00T N1（NVIDIA, 2025-03）

来源：[arXiv:2503.14734](https://arxiv.org/abs/2503.14734)（[html](https://arxiv.org/html/2503.14734)）；N1 数据金字塔的仿真侧数字与 [research-opensource.md](research-opensource.md) §6 一致，此处补齐论文一手细节。

- **数据金字塔**：真机 88 小时（GR-1 遥操作，VIVE tracker + Xsens 手套）+ OXE + AgiBot-Alpha 140k 轨迹；**神经轨迹 ~827 小时**（在 88h 真机数据上微调图生视频模型、换语言 prompt 生成，≈10× 增殖）；**仿真 78 万条**（DexMimicGen，≈6,500 小时，11 计算小时生成）；底座为 Ego4D/Ego-Exo4D/EPIC-KITCHENS 等人类第一视角视频。
- **无动作数据的动作标签（对我们 human 轨最重要）**：两条路——LAPA 式 **VQ-VAE 潜在动作**（帧对 → 统一潜在动作空间，人类/机器人共用）；**IDM 逆动力学模型**（在真机数据上训练）给神经轨迹打伪动作标签。
- **生成数据的清洗**：生成视频经"过滤 + 重标注"后处理——商用多模态 LLM 当裁判，对下采样 8 帧样本过滤、对不服从指令的视频重写 caption。**生成数据也要过质量门**，与我们 curation L3 VLM 审计同构。
- **表征**：流匹配（Beta 分布采 τ，s=0.999），动作块 H=16，推理 K=4 步；DiT 交替 cross/self-attention + adaLN；具身特定的 MLP 编解码器处理各机器人不同的状态/动作维度（**每具身一对 MLP 头，而非零填充**——与 π0 不同的第二种统一方案）。System 2 (VLM) 10 Hz / System 1 (DiT) 120 Hz。
- **算力**：2.2B 参数，最多 1024 GPU，预训练 **~50,000 H100 GPU 小时**，batch 1024 × 200k 步；后训练 batch 128–1024 × 20k–60k 步。

### 1.4 OpenVLA / OpenVLA-OFT（Stanford 等, 2024-06 / 2025-02）

来源：[arXiv:2406.09246](https://arxiv.org/abs/2406.09246)（[html v3](https://arxiv.org/html/2406.09246v3)）

- **混合与清洗（OXE 路线的标准操作）**：OXE 全集 2M+ 轨迹 → 过滤到 970k：只留"至少一个第三人称相机 + 单臂末端执行器控制"的操作数据集；沿用 **Octo 的启发式混合权重**（降权/移除低多样性数据集、升权任务/场景多样性大的）；DROID 以 10% 保守权重加入，但因"动作 token 准确率持续偏低"在**最后 1/3 训练中被移除**——数据集级回退是实际操作中的常态。最大权重：Bridge 13.3%、Fractal 12.7%、Kuka 12.7%（论文 Table 3 共 30 个数据集）。
- **动作离散化（第一代标准方案）**：每维 256 bins，按训练数据 **1%–99% 分位数**均匀分 bin（抗离群值），覆写 Llama 词表中 256 个最少用 token。输出 7 维动作。
- **算力**：7B 模型，64×A100 × 14 天 = **21,500 A100 小时**，batch 2048，27 个 epoch。推理 bf16 15GB、RTX 4090 上 ~6 Hz。
- OpenVLA-OFT（[arXiv:2502.19645](https://arxiv.org/abs/2502.19645)，RSS 2025）：微调配方研究——**并行解码 + 动作分块 + 连续动作 + L1 回归目标**替代自回归离散 token，动作生成吞吐 **26×**、LIBERO 四套件平均成功率 **76.5%→97.1%**；ALOHA 真机上超 π0/RDT-1B 最多 15 个百分点。结论：离散 token 是预训练便利，部署前应换连续动作头（与 π0.5 两阶段结论互相印证）。

### 1.5 RDT-1B / RDT2（清华 TSAIL, 2024-10 / 2026-02）

来源：[arXiv:2410.07864](https://arxiv.org/abs/2410.07864)（[html](https://arxiv.org/html/2410.07864)）、[arXiv:2602.03310](https://arxiv.org/abs/2602.03310)

- **RDT-1B 混合**：46 个数据集（RT-1 130K、DROID 76K、RH20T 110K 等，21TB，百万级轨迹）；数据集权重按 **√N 初始化 + 人工质量修正**——又一处"温度加权 + 质量人判"的组合。
- **动作空间统一（第三种方案，最工程化）**：**128 维物理可解释统一动作向量**——0–49 右臂、50–99 左臂、100–102 移动底盘、103–127 保留位；各机器人原生动作按物理含义映射进对应槽位，缺失维度补零。单臂机器人一律映射到"右臂"段。这是**跨具身 schema 设计的直接参考**（对比 π0 的"padding 到最大维"和 GR00T 的"每具身 MLP 头"）。
- **表征**：1.2B DiT 扩散（QKNorm/RMSNorm/交替条件注入），DPM-Solver++ 把采样从 100 步降到 5 步，6 Hz 块频率 / 38 Hz 动作频率。微调数据为自采 ALOHA 双臂 66K+ episodes（300+ 任务、100+ 物体、15+ 房间），指令用 GPT-4-Turbo 改写增广。
- **算力**：预训练 **48×H100 × 1 个月**；微调同规模 3 天/130K 步；机上推理 RTX 4090。
- **RDT2**：**10,000+ 小时 UMI 手持夹爪数据**（多样家庭场景、具身无关采集）+ 7B VLM 底座；三阶段配方 = **RVQ 残差向量量化动作 token → 流匹配 → 蒸馏**实时推理；首批"同时零样本泛化到未见物体/场景/指令/机器人平台"的模型之一。**这是 device 轨（UMI 式）可以独立支撑 0→1 预训练的最强证据**（呼应 [research-generalist-dora.md](research-generalist-dora.md) 的 Data Hands 判断）。

### 1.6 SmolVLA（Hugging Face, 2025-06）——社区数据清洗的直接样板

来源：[arXiv:2506.01844](https://arxiv.org/abs/2506.01844)（[html](https://arxiv.org/html/2506.01844)）

对我们最有参考价值的一篇，因为它的输入正是**未策划的 LeRobot 社区数据集**——与我们清洗产物同一格式、同一噪声形态：

- **混合**：481 个 HF 社区数据集，22.9K episodes / 10.6M 帧（比同行小一个数量级），数据集级筛选维度 = 具身类型、episode 数、整体质量、帧覆盖。
- **清洗两板斧**：(a) 任务标注噪声（占位符、缺失指令）→ 用 Qwen2.5-VL-3B 从代表帧**自动重写任务描述**；(b) 相机命名混乱（`images.laptop` 可能是顶/侧/腕任意视角）→ **人工归一化到 OBS_IMAGE_1/2/3**（顶、腕、侧优先级）。→ 我们 schema 的相机语义命名 + VLM 标注器正是要在入湖时消灭这两类问题。
- **表征与规模**：450M（动作专家 ~100M），SmolVLM-2 骨架只取前 16 层 LLM，流匹配动作专家、块长 n=50、每帧 64 视觉 token；异步推理（PolicyServer/RobotClient）任务完成快 30%。
- **算力**：主训练 4 GPU（单 GPU 可复现），项目总耗 **~30k GPU 小时**——0→1 预训练的下界参考。

### 1.7 GR00T N1.5 / N1.6（NVIDIA, 2025-05 / 2026）

来源：[GR00T-N1.5-3B 模型卡](https://huggingface.co/nvidia/GR00T-N1.5-3B)、[GR00T-N1.6-3B 模型卡](https://huggingface.co/nvidia/GR00T-N1.6-3B)、[GR00T-Dreams 仓库](https://github.com/NVIDIA/GR00T-Dreams)

- N1.5 两个数据侧升级：**FLARE**（Future Latent Representation Alignment）——对齐未来状态的潜在表征而非逐像素生成未来帧，使模型能直接从人类第一视角视频学习；**DreamGen**——用 Cosmos 世界基础模型从单张图 + 语言指令生成合成神经轨迹，学习遥操作数据中不存在的新行为。
- N1.6 继续该配方：真机 + Isaac GR00T Blueprint 合成数据的混合（双臂/半人形/人形），模型保持 3B 开源。
- 趋势判断：GR00T 系的迭代方向不是换架构，而是**持续加厚数据金字塔的中层（世界模型生成数据）**——见第 2 节 Cosmos。

### 1.8 WALL-OSS / Wall-OSS-0.5（自变量机器人 X Square, 2025-09 / 2026-05）

来源：[Wall-OSS-0.5 技术报告 arXiv:2605.30877](https://arxiv.org/html/2605.30877)、[wall-x 仓库](https://github.com/X-Square-Robot/wall-x)

其技术报告是目前**清洗步骤写得最具体的一手来源**，与我们管线逐项可对照：

- **混合**：机器人动作数据每 epoch 100 万+ 轨迹、20+ 具身（自采 ~60% / 开源 ~40%，开源含 RoboMIND v1/v2、DROID、BRIDGE v2、Fractal 等 10 个精选集）；多模态语料 ~9,000 万样本（7,800 万开源 + **1,200 万"具身桥接样本"**——由动作轨迹合成的多模态样本）；动作:多模态 batch 比 9:1。
- **清洗五步（一手明细）**：① 跨平台动作空间统一到共享语义 schema；② 视频/动作帧按时间戳对齐；③ 错误数据修复（**相机接反、异常位姿**——真实车队数据的典型故障模式）；④ **静止帧过滤**（去除空转动作）；⑤ **幂采样 p=0.5** 平衡源间/源内不均衡。——与我们 curation L1/L2 门几乎一一对应，验证了我们的设计。
- **训练**：单阶段"梯度桥接协同训练"三目标——离散 RVQ 动作 token 交叉熵（主梯度桥，直接更新 VLM 骨架）+ 多模态交叉熵（λ=0.01）+ 流匹配（λ=0.01，部署用）。动作 tokenizer 为自学习的视觉对齐 RVQ（**替代 FAST**）。动作空间 26 维（双臂 ee 位姿 6D 旋转相对量 + 夹爪 + 底盘 + 升降 + 头）。
- **规模与结果**：4B（Qwen2.5-VL-3B 骨架 + MoT 双专家），推理 15 Hz@448²；零样本 17 任务平均进度 51.1%（未见任务 53.6% 反高于已见）；微调后 60.5% vs π0.5 的 43.0%。卖点即标题："Pretrain Once, Act Anywhere"——预训练性能逼近后训练水平。

### 1.9 Embodied-R1（2025-08, ICLR 2026）——"指点"中间表征路线

来源：[arXiv:2508.13998](https://arxiv.org/abs/2508.13998)、[官方仓库](https://github.com/pickxiguapi/Embodied-R1)

- 3B VLM，以**指点（pointing）作为具身无关的中间表征**弥合"看见→做到"鸿沟；自建 Embodied-Points-200K 数据集，两阶段**强化微调（RFT）**课程 + 多任务奖励。
- 零样本：SIMPLEREnv 56.2%、8 个真机 XArm 任务 87.5%，无任务特定微调。
- 对我们的意义：指点/示能标注是 VLM 标注器可以低成本产出的**动作无关监督信号**——human 轨（无动作标签）除了潜在动作外的第二条利用路径。

三点横向规律：

1. **动作空间统一的四种可抄方案**：π0 零填充（最简）、RDT 128 维物理槽位（最可解释、适合我们 schema）、通义 QwenRobot-Manip 80 维掩码统一状态-动作（槽位 + 二值有效掩码，与 RDT 同思路但更紧凑，见 [research-qwen-robotics.md](research-qwen-robotics.md) §2）、GR00T 每具身 MLP 头（模型侧解决，数据侧无需统一）。我们四轨 schema 应在 export 层支持前三种输出（槽位视图 + 零填充视图）。
2. **离散→连续两阶段成为共识**（π0.5、Wall-OSS、RDT2 三家独立收敛）：离散动作 token（FAST 或 RVQ）做预训练的"梯度桥"，流匹配/扩散做部署表征。
3. **目标域数据占比可以很低**（π0.5 的 2.4%、GR00T 真机 ~1%）：预训练价值主要来自跨域覆盖，**这直接抬高 human/sim/device 轨的战略权重**。

## 2. WAM/世界模型路线

结论先行：截至 2026-08，世界模型在机器人预训练中的**实战定位是"数据增殖器 + 学习型评测器"，不是策略基座的替代**。唯一把世界模型直接当"可规划基座"的量产证据是 V-JEPA 2-AC，但它只做短视野伸抓任务。VLA 与 WM 是互补关系：WM 消费的正是 VLA 管线清洗后的同一批视频数据。

### 2.1 NVIDIA Cosmos——WFM 平台 + 唯一开源的视频策展管线

来源：[arXiv:2501.03575](https://arxiv.org/abs/2501.03575)（[html](https://arxiv.org/html/2501.03575v1)）

- **定位**：Physical AI 的"世界基础模型平台"——预训练通用 WFM，后训练成下游专用世界模型（机器人/自驾）。开源开放权重 + tokenizer + **视频策展管线**（宽松 license）。
- **数据规模**：~2,000 万小时原始视频 → ~1 亿条 2–60 秒 clip（预训练 1e8、微调 1e7）。
- **五步视频策展管线（业界唯一完整公开的一手管线，与我们 curation 五阶段直接对标）**：① 切分（TransNetV2 镜头边界检测）→ ② 过滤（运动/画质/文字覆盖/视频类型）→ ③ VLM 标注（统一 caption）→ ④ 去重（GPU k-means, k=10,000，去掉 ~30%）→ ⑤ 分片（按分辨率/宽高比打包 webdataset）。**"去重去掉 30%"是我们 embedding 去重阶段的量级锚点。**
- **模型**：扩散 WFM（7B/14B, Text2World/Video2World）+ 自回归 WFM（4B/12B）；连续/离散双 tokenizer（压缩率 4×8×8 至 8×16×16）。
- **算力**：**10,000×H100 × 3 个月**——WFM 从零预训练的成本量级，说明我们不该自训 WFM，应消费其开源权重（GR00T 的 DreamGen 即此用法，见 §1.7）。

### 2.2 1X 世界模型——车队数据学出来的评测器

来源：[1X 官方博客](https://www.1x.tech/discover/1x-world-model)

- 动作条件视频生成：给初始帧 + 候选动作序列，"想象"世界如何演化——用途是**在数百万场景上评测策略**而不上真机（解决真实环境漂移导致评测不可复现的问题），即"从原始传感器数据直接学一个模拟器"。
- 训练数据：EVE 人形车队数千小时家庭/办公移动操作。
- 开源：**100+ 小时向量量化视频（Apache 2.0）** + 基线模型（Llama/GENIE 架构）+ 三阶段带奖金的 World Model Challenge。
- 定位启示：世界模型作为**评测协议的一部分**（策略回归测试），这是数据管线可以直接支撑的消费场景。

### 2.3 Genie 3（DeepMind, 2025-08）——生成式交互环境，未开源

来源：[DeepMind 官方博客](https://deepmind.google/blog/genie-3-a-new-frontier-for-world-models/)（官方域名抓取受限，内容经 [OpenCV 转述](https://opencv.org/blog/genie-3/) 与 [TechCrunch](https://techcrunch.com/2025/08/05/deepmind-thinks-genie-3-world-model-presents-stepping-stone-towards-agi/) 交叉印证）

- 文本 prompt → 实时交互环境，720p/24fps，一致性维持数分钟（上代仅数秒），涌现物体恒存性；可提示世界事件。
- 具身定位：给 SIMA 等 agent 提供无限训练场景（agent 向 Genie 3 发导航动作追求目标）。
- 官方自认限制：动作空间有限、多智能体交互难、无法精确模拟真实地点。**限定研究预览，不开源**——对我们只有方向参考价值，无工程可用性。

### 2.4 V-JEPA 2 / V-JEPA 2-AC（Meta, 2025-06）——潜空间世界模型直接做规划

来源：[arXiv:2506.09985](https://arxiv.org/abs/2506.09985)

- V-JEPA 2：100 万+ 小时互联网视频自监督预训练（潜空间预测，非像素生成）；运动理解 SSv2 77.3%、EK-100 动作预期 SOTA、8B 规模视频 QA 84.0 (PerceptionTest)。
- **V-JEPA 2-AC（对我们最重要）**：仅用 **<62 小时无标注 DROID 机器人视频**后训练出动作条件世界模型，在两个不同实验室的 Franka 臂上**零样本规划抓放**——不采环境特定数据、不做任务特定训练。
- 定位：与 VLA 相反的路线——不直接预测动作，而是学世界模型后用规划（MPC）出动作。代码与权重开源（Meta AI 仓库）。
- 启示：**"海量无动作视频 + 极少量机器人交互数据"的配比哲学**与 π0.5（目标域 2.4%）殊途同归；human 轨视频对 WM 路线同样是一等公民燃料。

### 2.5 WHAM / Muse（Microsoft Research, 2025-02, Nature）——游戏域的 WAM 原型

来源：[Microsoft 官方博客](https://www.microsoft.com/en-us/research/blog/introducing-muse-our-first-generative-ai-model-designed-for-gameplay-ideation/)（Nature 论文 s41586-025-08600-3 需订阅）

- "World and Human Action Model"：**同时生成游戏画面与手柄动作**（视觉+动作联合序列建模）——WAM 这个词的出处之一。
- 数据：10 亿+ 图像-手柄动作对（Bleeding Edge 游戏，≈7 年连续人类游玩，EULA 授权采集）；模型 206M 与 1.6B 两档，生成分辨率 300×180。
- 开源：权重、样例数据、WHAM Demonstrator 经 Azure AI Foundry 开放。
- 定位：明确用于"gameplay ideation"（创意辅助）而非策略——**证明视觉+动作联合生成可行，但离机器人控制精度尚远**。

### 2.6 世界模型 × VLA 的关系判定

| 系统 | 定位 | 对 VLA | 开源 |
|---|---|---|---|
| Cosmos | 数据增殖（DreamGen→GR00T）+ 后训练底座 | 互补：造数据 | 权重+tokenizer+策展管线 |
| 1X WM | 学习型评测器 | 互补：评测 | 100h 数据+基线（Apache 2.0） |
| Genie 3 | agent 训练场 | 互补：造环境 | 不开源 |
| V-JEPA 2-AC | 规划型策略基座 | **部分替代**（短视野任务） | 开源 |
| WHAM | 视觉+动作联合生成原型 | 平行探索 | 开源（Azure） |

对本仓库：世界模型是我们数据的**下游消费者**（Cosmos 微调需 1e7 clip 量级的策展视频；1X 式评测器需要车队视频+动作对），不是我们要自建的东西。管线需保证：视频 clip 化、caption、去重的产物既能喂 VLA 也能喂 WM 微调——Cosmos 五步管线与我们 curation 阶段的对应关系（§2.1）说明格式上不需要额外分叉。

## 3. 0→1 预训练的工程要件

### 3.1 数据加载与打包

- **分片打包是标配**：Cosmos 把 1e8 clip 按分辨率/宽高比打包成 **webdataset**（[arXiv:2501.03575 §3.6](https://arxiv.org/html/2501.03575v1)）；OXE 系用 RLDS/TFRecord；LeRobot v3 用多 episode 合并 parquet+mp4 与原生流式加载（见 [research-opensource.md](research-opensource.md) §1）。共同点：**训练时不碰"每 episode 一文件"**——我们 export 层选 LeRobotDataset v3 已符合。
- **采样器承担配比逻辑**：π0 的 n^0.43 任务-机器人加权、RDT 的 √N+质量修正、Wall-OSS 的 p=0.5 幂采样与 9:1 动作:多模态 batch 比——混合比例是**运行时采样器参数，不是静态数据集切分**。我们的数据集层应把"每 (track, task, embodiment) 组合的样本计数"作为元数据导出，供采样器计算权重。
- 吞吐锚点：Generalist 自报"每训练日 6.85 年真实操作经验"的加载吞吐（见 [research-generalist-dora.md](research-generalist-dora.md)），对应 O(10K) CPU 核的持续多模态预处理——0→1 阶段用不到，但说明视频解码是长期瓶颈（AV1+torchcodec 选型正是为此）。

### 3.2 训练基础设施规模参考（各家公开值汇总）

| 训练 | 算力 | 换算量级 |
|---|---|---|
| OpenVLA 7B 预训练 | 64×A100 × 14 天 = 21.5k A100h（[论文](https://arxiv.org/html/2406.09246v3)） | ~$4–6 万云价 |
| GR00T N1 2.2B 预训练 | ~50k H100h，≤1024 GPU（[论文](https://arxiv.org/html/2503.14734)） | ~$15 万云价 |
| RDT-1B 预训练 | 48×H100 × 1 个月 ≈ 35k H100h（[论文](https://arxiv.org/html/2410.07864)） | ~$10 万云价 |
| SmolVLA 450M | 主训练 4 GPU；全项目 ~30k GPUh（[论文](https://arxiv.org/html/2506.01844)） | 单卡可复现 |
| π0 3.3B | 未披露 GPU；700k 步 | — |
| Cosmos WFM（对照组） | 10,000×H100 × 3 个月（[论文](https://arxiv.org/html/2501.03575v1)） | ~$5,000 万级，不可自建 |
| π0 微调（openpi 官方口径） | LoRA >22.5GB 显存（单 4090 可）；全参 >70GB（单 A100/H100）（[openpi](https://github.com/Physical-Intelligence/openpi)） | 单卡起步 |

量级结论：**VLA 0→1 预训练是 1e4–1e5 GPU 小时的事，WFM 0→1 是 1e7 GPU 小时的事**——前者创业公司/实验室可为，后者只能消费开源权重。

### 3.3 课程设计（预训练→中训练→后训练）

各家阶段划分收敛为三段式：

1. **预训练**（覆盖优先）：杂而全的跨具身混合。π0.5 用 FAST 离散 token 跑 280k 步；Wall-OSS 例外地单阶段但靠三目标加权实现同等效果；GR00T 用全金字塔 batch 1024 × 200k 步。
2. **中训练/后训练**（质量优先）：换连续动作表征（π0.5 +80k 步流匹配；OFT 连续 L1 头），数据换成精策划目标域数据（π0"consistent and fluent strategy"；GR00T 每具身 20k–60k 步）。
3. **经验后训练（2025-11 起的新第三段）**：π*0.6 的 **RECAP**（[arXiv:2511.14759](https://arxiv.org/html/2511.14759)、[官方博客](https://www.pi.website/blog/pistar06)）——演示 → 真机纠错（expert corrections）→ 自主试错 RL（advantage-conditioned policy），把最难任务吞吐翻倍、失败率减半（18 小时连续做咖啡、50 件新衣物折叠、59 个工厂纸箱）。含义：**数据管线必须能回收"策略自主 rollout + 人工纠错片段"作为新数据轨**——正对应我们 robot 轨的车队回流设计。

### 3.4 评测协议

- **仿真基准的事实标准**：LIBERO（四套件，OpenVLA-OFT/SimpleVLA-RL 都以此报数）、SIMPLEREnv（real-to-sim，Embodied-R1 用）、RoboCasa/DexMimicGen 系（GR00T）；Isaac Lab-Arena 做批量回归（见 [research-opensource.md](research-opensource.md) §6）。
- **真机协议**：成功率之外，**任务进度分**（Wall-OSS 17 任务平均 progress）与**吞吐/失败率/介入率**（π*0.6 的营业级指标）正在成为标准；Generalist 用验证 MSE + 反向 KL + 盲测 A/B（见 [research-generalist-dora.md](research-generalist-dora.md)）。
- **学习型评测**：1X 世界模型路线（§2.2）——用 WM 离线评测策略，回避真实环境漂移。
- 对我们：评测数据集（held-out episode 按 scene/object/operator 切分）应在 curation 层就固定并版本化，否则消融不可比。

## 4. 学术动向（2025-2026）

### 4.1 跨具身预训练：从"归一化拼数据集"到"具身无关采集"

OXE 式拼接（OpenVLA）→ 统一动作 schema（RDT 128 维槽位、Wall-OSS 26 维语义空间）→ **具身无关硬件采集**（RDT2 的 10,000h UMI，[arXiv:2602.03310](https://arxiv.org/abs/2602.03310)；Generalist Data Hands）。趋势是把跨具身问题从模型侧前移到**采集硬件侧**：末端执行器空间数据天然跨平台。这直接抬高我们 device 轨的地位。

### 4.2 动作分词：FAST 之后是学习型 RVQ

- **FAST**（[arXiv:2501.09747](https://arxiv.org/abs/2501.09747)）：逐维逐步分 bin 在高频/灵巧数据上失效 → DCT 频域压缩 + BPE；通用版 FAST+ 在 100 万条真实轨迹上训练，可跨形态/动作空间/频率复用；π0+FAST 可扩到 10k 小时数据、训练时间比扩散 VLA 少至 1/5。
- 2026 年迭代：**学习型残差向量量化（RVQ）取代 FAST**——Wall-OSS-0.5 的视觉对齐 RVQ tokenizer（[arXiv:2605.30877](https://arxiv.org/html/2605.30877)）、RDT2 的 RVQ→流匹配→蒸馏三阶段。离散 token 的价值定位收敛为"预训练梯度桥"（§1.10）。
- 对我们：动作数据只需存**原始连续值 + 频率元数据**，tokenizer 是训练侧的事；但 schema 必须保真高频（100–200 Hz）原始动作，因为 FAST 论文证明低频重采样会毁掉高频任务的可分词性。

### 4.3 少样本适应与物理提示

GEN-1.5 的"演示即提示"（3–12 秒演示、零梯度、59%±10%；10 步微调 83%±9%，详见 [research-generalist-dora.md](research-generalist-dora.md)）与 V-JEPA 2-AC 的"62 小时无标注视频出零样本规划器"（§2.4）从两个方向证明：**预训练基座之上，适应成本正在坍缩到分钟级数据**。评测体系需加"少样本适应"维度（该结论已写入 research-generalist-dora.md 启示 5，此处不重复）。

### 4.4 RL 后训练（RLinf/HIL-SERL 之外）

- **SimpleVLA-RL**（[arXiv:2509.09674](https://arxiv.org/pdf/2509.09674)，ICLR 2026，[仓库](https://github.com/PRIME-RL/SimpleVLA-RL)）：基于 veRL 的端到端规则奖励在线 RL；OpenVLA-OFT 上 LIBERO-Long 达 97.6；**冷启动仅 1 条轨迹/任务时 17.3→91.7（+430%）**——RL 大幅压低 SFT 数据门槛。
- **π*0.6 RECAP**（§3.3）：首个营业级真机 RL 结果（advantage conditioning 而非 policy gradient，绕开真机上不稳定的在线 RL）。
- 基建化趋势：异步/分布式 VLA-RL 框架涌现——RL-VLA³（[arXiv:2602.05765](https://arxiv.org/abs/2602.05765)）、D-VLA（[arXiv:2605.13276](https://arxiv.org/pdf/2605.13276)）、RobustVLA（[arXiv:2511.01331](https://arxiv.org/pdf/2511.01331)）；**RehearseVLA**（[arXiv:2509.24948](https://arxiv.org/html/2509.24948v4)）用物理一致世界模型做"排练式"后训练——RL 与世界模型两条线在此汇合。
- 对我们：RL 后训练消费的是**带奖励/成功标注的 rollout**，我们 episode schema 的 QC 状态机（成功/失败/介入标记）就是奖励信号的雏形。

### 4.5 数据 scaling law：多样性幂律获多方验证

- **Lin et al.**（[arXiv:2410.18647](https://arxiv.org/abs/2410.18647)）：策略泛化与**环境数/物体数**呈幂律，与单环境演示数无关——每环境演示数过阈值后边际归零；4 个采集员一下午的多环境数据即可在新环境新物体上 ~90% 成功率（总量 4 万演示、1.5 万真机 rollout 验证）。
- Generalist GEN-0 的 L(D) 幂律 + 模型骨化相变（1B 吸收不了、7B+ 才能吃大数据，见 [research-generalist-dora.md](research-generalist-dora.md)）从工业规模印证同一形态。
- **尚无公开反驳**；但注意两者度量不同（Lin 测泛化成功率、GEN-0 测验证损失），"多样性>数量"对采集预算的指令是一致的：**扩场景/物体/操作者数，而不是扩单任务时长**——这是我们缩放消融切分器（按 scene/task/operator 切）的理论依据。

## 5. 可行计划：从本仓库清洗产物到 0→1 预训练

前提：本仓库处于 M1（采集与格式），四轨 schema 已定，导出目标 LeRobotDataset v3。以下每阶段有明确的数据门槛与放行条件，依据均来自前四节的一手数字。命名说明：本节**阶段 A/B/C 是数据规模阶段**；[training-pipeline.md](training-pipeline.md) §2 的 **Stage A–D 是训练课程阶段**，二者对应关系写在那里。

### 阶段 A（M1 内，0 预算训练）：用"微调已有基座"验证管线正确性

**先别 0→1。** openpi（Apache 2.0）π0/π0.5 微调只需 LeRobot 格式 + 归一化统计，LoRA 单张 4090（>22.5GB）即可跑（§3.2）；SmolVLA 单 GPU 可全流程复现。

- 数据门槛：**单任务 10–50 小时精策划 robot 轨**（GR00T 全部真机数据也只有 88h；π0 后训练哲学=小而精）。
- 放行条件：我们 export 的数据集能不改代码直接进 openpi/lerobot 训练循环，微调后真机成功率显著高于零样本——这证明**时间戳对齐、动作归一化统计、相机命名（SmolVLA 教训，§1.6）全部正确**。管线正确性只有被一次真实训练消费过才算验证。
- 同步落地：把 Wall-OSS 清洗五步（§1.8）对照进 curation 实现清单——静止帧过滤、相机接反检测、时间戳对齐校验我们已有设计，幂采样计数元数据要补进 export。

### 阶段 B（数据到 500–1,000 小时级）：小模型 0→1 预训练

- 数据门槛：**混合等效 ≥1,000 小时 / 数万 episodes**，且按 Lin 幂律（§4.5）优先扩**场景数×物体数×操作者数**而非时长；四轨映射数据金字塔：human 轨视频（FLARE/潜在动作/指点标注三条消费路径，§1.7/1.3/1.9）打底层，sim 轨（DexMimicGen 增殖 + Cosmos/DreamGen 神经轨迹）做中层，device 轨（UMI）与 robot 轨做顶层——GR00T 配比（真机 ~1%）和 π0.5（目标域 2.4%)证明顶层小不碍事。
- 模型规模依据：数据 <1e3 小时时选 **0.5B 级**（SmolVLA 证明 450M 在 23K episodes 上成立；GEN-0 骨化相变说明小数据喂大模型反而浪费，§4.5）。
- 表征：预训练用离散动作 token（FAST+ 现成可用，§4.2），后训练换流匹配头（三家共识，§1.10）。
- 预算量级：**5k–30k GPU 小时**（SmolVLA 全项目 30k 上限参考），云价 $1.5–10 万。
- 放行条件：LIBERO/SIMPLER 上不弱于同规模开源基线；内部 held-out（按 scene/operator 切，curation 期固定，§3.4）超过"直接微调开源基座"的对照组——**若不超，说明数据还不够，继续留在微调路线**（这是最重要的止损门）。

### 阶段 C（数据到 5,000–10,000 小时级）：2–4B 跨具身预训练

- 数据门槛：RDT2 的 10,000h UMI（§1.5）与 FAST 的"10k 小时可扩"（§4.2）共同指向 **1e4 小时**是当前"证明过能出跨具身零样本泛化"的量级；具身数 20+（Wall-OSS）为混合广度参考。
- 模型规模依据：跨过 1e3–1e4 小时后升到 **2–4B**（GR00T 2.2B / π0 3.3B / Wall-OSS 4B 全部落在此带；7B 仅 OpenVLA/RDT2 且都有效率问题）。骨架用现成 VLM（Qwen2.5-VL/PaliGemma/SmolVLM），**永远不从零训 VLM**。
- 动作空间统一：export 层实现 RDT 式 128 维物理槽位向量（§1.5)作为可选输出视图，同时保留原生维度 + 零填充视图（π0 式）——两种主流训练栈都能直接吃。
- 预算量级：**3 万–10 万 H100 小时**（GR00T 5 万 / RDT 3.5 万为锚），云价 $10–30 万；配比逻辑全部走采样器权重（n^α 温度加权，α∈[0.4,0.5] 为三家公开值域）。
- 课程：离散预训练 → 连续后训练 → **RECAP 式经验后训练**（回收车队 rollout + 纠错片段，schema 的 QC 状态机直接当奖励标注，§3.3/4.4）。

### 验证序列（贯穿 B/C，先仿真后真机）

1. 仿真回归：LIBERO + SIMPLEREnv 每数据版本必跑（数据集迭代的 CI）；Isaac Lab-Arena 做批量消融。
2. 缩放消融：每次数据翻倍跑 L(D) 拟合（GEN-0 式）+ 按环境/物体数切分的幂律检验（Lin 式）——两条曲线共同指挥下一步采集预算。
3. 真机：盲测 A/B + 任务进度分 + 介入率（§3.4）；补"少样本适应"维度（1 条演示 / 10 步微调后的成功率，§4.3）。
4. 世界模型评测器（可选，数据到位后）：1X 式动作条件视频模型微调（消费与 VLA 相同的清洗产物，§2.6），做离线策略预筛。

### 明确不做

- 不自训世界基础模型（1e7 GPU 小时量级，§3.2）；消费 Cosmos 开源权重做 DreamGen 式数据增殖。
- 不自研动作 tokenizer（FAST+ 够用，RVQ 等有开源实现再跟进）。
- 不在数据 <1,000 小时时启动任何 0→1 预训练（阶段 B 止损门）。

## 6. 结论

1. **清洗→预训练的衔接点已经标准化**：LeRobot 格式 + 归一化统计 + 分层语言标注 + 采样计数元数据，就是预训练侧对数据管线的全部接口要求；Wall-OSS 公开的清洗五步与我们 curation 设计逐项重合，Cosmos 公开的视频五步与我们 human 轨策展逐项重合——**本仓库的架构方向被 2025-2026 全部一手证据支持，无需返工**。
2. 动作表征之争已收敛：**离散 token（FAST/RVQ）做预训练梯度桥 + 流匹配做部署头**，两阶段课程是三家独立结论。
3. 世界模型不是 VLA 的替代而是其数据的第二消费者（增殖 + 评测）；唯一要自建的 WM 资产是（远期）1X 式评测器。
4. 数据侧最高杠杆的事实：**目标域数据占比可以低到 1–2.4%**、**多样性幂律**、**RL 把冷启动 SFT 压到 1 条轨迹/任务**——三者共同指向：采集预算投给场景/物体/操作者广度，精策划小数据留给后训练，rollout 回流留给经验后训练。
5. 预算现实：0→1 预训练是 1e4–1e5 GPU 小时、$10 万量级的事，且只有在自有数据过 1,000 小时等效后才值得启动；在此之前，微调 openpi/SmolVLA 是验证数据管线的最快闭环。
