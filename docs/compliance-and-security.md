# 合规与安全：区域 · Creator 协议 · 保留期 · 访问控制 · 安全基线 · 劳动与人身安全

> 2026-09-08。把 index-replica-plan §0 原则 4"隐私是生存问题"与 §8.3 的一句话对策展开成可执行实体。本文不是法律意见；每个区域上线前需法务按本文清单出具意见（governance R-01/R-11）。

## 1. 区域矩阵与跨境路径

| 区域 | 主要法规 | 数据驻留 | 跨境训练 | 上线前动作 |
|---|---|---|---|---|
| 中国大陆 | 个保法、数据安全法、生成式 AI 管理办法 | raw 与个人信息境内存储 | 出境需安全评估/标准合同；**默认不出境**，训练在境内 | 个人信息保护影响评估（PIPIA）、算法备案评估 |
| 欧盟/英国 | GDPR/UK GDPR、AI Act | 欧盟区域 | SCC + 传输影响评估 | DPIA（家庭场景为高风险处理，必做） |
| 美国 | CCPA/CPRA、州生物识别法（IL BIPA 等） | 无强制 | 可 | 隐私声明、BIPA 州禁止人脸生物识别或单独同意 |
| 其他 | 逐国 | 逐国 | 逐国 | 未评估区域不开放 App |

实现：`region` 字段决定 bucket 区域与合规开关集（人脸处理方式、保留期、删除 SLA）；跨区训练只用**已脱敏的 training 区**数据，raw 不跨区。

## 2. Creator / 操作员协议要点

- 授权范围：录制内容用于机器人学习模型训练、评测、衍生数据集（含具身转换等派生产物）；是否允许对外发布数据集需**单独勾选**（open-source-strategy §3）。
- 期限与撤回：授权持续到撤回；撤回后 30 天内从 raw/curated/training 删除，**已训练完成的模型不回滚**但记录在案（deletions 表），后续数据集版本剔除——该条款必须在协议明示。
- 报酬：按通过策展的分钟数计酬，费率与信誉分级公示；争议处理流程。
- 旁观者：Creator 承诺告知同住人/在场人并取得口头同意；未成年人不得作为主要被摄对象；违规上传扣信誉并删除。
- 用工性质：默认承揽关系（独立贡献者），按区域法务确认；避免排班、强制时长等雇佣特征（governance R-11b）。

## 3. 旁观者与未成年人处置

- 端上：录制指示灯（硬连线）+ App 开始录制强提示；可选端上人脸模糊。
- 入湖强制：人脸检测 + 模糊（EgoBlur，Apache）；检出未成年人特征（年龄估计模型，⚠️license 待核查）的 episode 进人工审核队列，确认后整段拒收并从 raw 删除（这是"raw 永存"的合法例外之一）。
- 误模糊：脱敏前帧哈希留存 90 天供审计，误模糊率抽检进 QC；误模糊的 episode 标记 `flag:overblur`，不删除。
- 语音：环境音频默认不入训练集，仅口令段（`/event/task` 附近 ±2 s）保留转写文本，原音频 30 天删除。
- 家居 3D 孪生（Creator 场景扫描经 SimFoundry 重建的物体清单、布局、网格）：视为敏感个人数据，入网时**单独勾选同意**（可拒绝，拒绝则只能领通用任务）；按 `region` 驻留、不对外发布、不进 L1 可共享级；随 Creator 删除请求一并删除并传导到由其派生的 sim 轨 episode（`parent_episode_id` 链）。

## 4. 数据分级、RBAC 与审计日志

| 级别 | 内容 | 访问 |
|---|---|---|
| L3 受限 | raw 未脱敏视频、Creator 身份信息、支付信息 | 平台运维 + 合规专员；双人审批；只读 |
| L2 内部 | 脱敏后 curated、元数据、审核台 | 数据/策展/训练团队 |
| L1 可共享 | training 区脱敏数据集、统计指标 | 全员；对外按 open-source-strategy |

- 身份：SSO + 角色；服务账号最小权限；raw 区只有 ingest 写、审计读。
- 审计日志：所有 L3 访问、删除请求处理、数据集发布记录不可篡改（写一次存储），保留 3 年。
- 删除传导：`deletions` 表驱动，raw → curated → training → 数据集 manifest 剔除 → 受影响模型登记；SLA 30 天；每季度审计一次随机抽样删除请求是否真的删干净。

## 5. 加密与设备丢失

- 传输 TLS 1.3；静态加密（对象存储 SSE + 数据库 TDE）；设备本地存储加密（LUKS/文件系统级），密钥与 Creator 账号绑定，设备丢失可远程吊销。
- 设备丢失 SOP：App 一键报失 → 吊销设备证书 → 未上传数据视为泄露事件评估 → 通知义务按区域。
- 手机方案（P0）：录制文件存 App 私有沙箱，上传后本地删除。

## 6. 保留期政策（调和"raw 永存"）

| 数据 | 保留 | 例外 |
|---|---|---|
| raw（脱敏后存档） | 永久 | 撤回/删除请求、未成年人、违法内容、区域法规强制 |
| raw 脱敏前帧哈希 | 90 天 | 审计用 |
| 原始音频 | 30 天 | 口令转写文本永久 |
| Creator 身份/支付 | 关系终止后按财税法规（通常 5–7 年） | |
| 审核台记录 | 3 年 | |
| 中间产物 | 90 天（可重算） | |

"raw 永存"的准确表述：**脱敏后的原始 episode 永久保留，除非法律或数据主体要求删除**；CLAUDE.md 决策 4 的"隐私脱敏除外"即指此。

## 7. 安全基线

- 设备固件签名 + 安全启动；OTA 走签名包与灰度；固件版本进 EpisodeMeta。
- 端点鉴权：设备证书 + 短期 token；上传分片带内容哈希；ingest 网关拒绝无证书上传。
- 投毒防御：新账户全量审计；跨账户 embedding 碰撞；红队植入测试（data-platform §5）；训练前 held-out 泄漏检查；异常簇（单账户短期大量高相似上传）自动冻结。
- 内容安全：上传经违法/暴力/色情内容分类器（本地模型），命中进人工队列，确认后拒收并按法规处置。
- 供应链：依赖锁定（uv.lock）、镜像签名、模型权重哈希校验。

## 8. 劳动合规与上门服务安全

- 计酬透明：每笔计酬可追溯到通过策展的 episode 列表；申诉通道；最低有效时薪监测（通过率过低导致实际时薪低于当地最低标准的任务模板下线）。
- 双边市场（预约 Creator 上门）**H2 前不开放**；开放前提：背景审查流程、双向评价、保险、紧急联系机制、法务意见。
- 场地采集（Brookfield 式合作物业）：与物业签采集协议，张贴录制告示，划定禁录区域。

## 9. 与管线的接口

| 管线点 | 合规钩子 |
|---|---|
| recorder / App | `consent_ref`、`region` 必填；指示灯状态进 `/meta/health` |
| ingest | 人脸模糊强制；未成年人/内容安全分类；区域 bucket 路由 |
| curation | 审核员只见脱敏预览流；审核记录进 lineage |
| export | 只从 training 区读；数据集 manifest 记录 consent 版本集合 |
| 训练 | `training_runs` 记录 dataset_version，删除传导可查 |
| 对外发布 | open-source-strategy §3 的发布前检查单 |
