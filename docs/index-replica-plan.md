# 自研 Index 复刻方案：硬件-采集-平台-数据-训练-验证 全链路规划

> 2026-08-29。目标：自研一套对标 Figure Index 的众包第一视角数据采集系统（设备 + Creator App + 数据平台 + 策展/训练管线）。依据：[architecture.md](architecture.md)（Index 五阶段策展、Ego2Robot/PrimeU 学术印证）+ Meta [Aria Gen 2](https://ai.meta.com/blog/aria-gen-2-research-glasses-under-the-hood-reality-labs/) 硬件标杆。

---

## 0. 产品定义与设计原则

**产品 = 头戴录制设备 + Creator App + 数据平台**，产出"可恢复手部动作的任务级第一视角视频"。

四条设计原则（全链路贯穿）：

1. **为下游监督信号设计，不为观感设计**：设备存在的唯一理由是让"手在干什么"可被算法恢复（手部姿态 → EE 伪标签）。手部可见率是比分辨率更重要的指标。
2. **质量门前移**：Index 五阶段策展会丢弃大部分上传。每往端上前移一层过滤，云端成本和 Creator 的无效劳动都降一个量级。
3. **激励与反欺诈同构设计**：按分钟计酬必然催生刷量。计酬锚定"通过策展的分钟数"而非原始分钟，反欺诈是管线一等公民。
4. **隐私是生存问题**：众包进入真实家庭/工作场所，硬件级录制指示 + 合规设计（GDPR/CCPA/个保法）从 day one 内建，不能事后补。

## 1. 硬件架构（多采集方式并行 + 三阶段策略）

### 1.0 采集方式矩阵：不押注单一形态

Generalist（Data Hands 手持夹爪对，50 万+ 小时）与 Figure（Index 头戴视频 + 遥操作）证明：**采集方式是组合题不是单选题**。各方式产出不同监督信号，共用同一平台/策展/数据集层：

| 采集方式 | 动作标签 | 任务覆盖 | 单位成本 | 主要消费者 |
|---|---|---|---|---|
| 头戴第一视角（Index 式，本方案主线） | 无 → 视觉伪标签 | 全部日常任务 | 低 | 预训练/导航/S2 语料 |
| **手持夹爪对（UMI/Data Hands 式，新增 device 轨）** | **硬件真值**（SLAM 位姿 + 开合编码） | 受限于夹爪形态 | 低（开源图纸） | 动作专家预训练/微调、演示库 |
| 穿戴孪生夹爪手套（Sunday Skill Capture 式，device 轨低成本档） | **硬件真值**（夹爪级；头戴观测需具身转换抹除人体） | 简化夹爪任务子集 | 低（软手套 $200–400 + 相机帽，可与头戴设备共用） | 动作专家预训练（P1 评估，见 [research-sunday.md](research-sunday.md)） |
| 穿戴孪生灵巧手（TwinDEX 式，device 轨升级路线） | **硬件真值（含逐指），零重定向** | 灵巧手任务子集 | 中（外骨骼+同构末端成对） | 灵巧手动作专家（P1/P2 评估，见 [research-twindex.md](research-twindex.md)） |
| 遥操作真机（robot 轨） | 真值 + 目标本体系 | 受限于机器人能力 | 极高 | 微调封顶、RL 示教 |
| 仿真（sim 轨） | 真值 | 受限于仿真保真度 | 边际近零 | S0/增殖/评测 |
| 动捕手套（小规模） | 真值（全手关节） | 标定专用 | 高 | 伪标签金标准（§4 质量分刻度） |

配比由下游消融裁决（§6），不预设。schema 层四轨（robot/human/device/sim）共用 EpisodeMeta。device 轨实施细节（硬件方案对比、fdp 接入、校准设计）见 [device-track-umi.md](device-track-umi.md)；各设备的构型级横评（多角度视图 + 五因子任务成功因果链）见 [device-landscape.md](device-landscape.md)。

### P0（0–3 个月）：不自研，先跑通链路

**双端并行**：(a) 手机胸戴/运动相机头带（human 轨）；(b) **UMI 开源手持夹爪 1–2 对（device 轨）**——图纸/软件全开源、单 MP4 落盘，比自研头戴更快出有动作真值的数据。目的：用最便宜的方式把平台、策展、训练闭环全部跑通，用真实数据反推设备规格（帧率、FOV、俯角、手部可见率），并用 device 轨真值**校准 human 轨伪标签**。学术先例：AoE/EgoKit 以手机为基座；UMI（arXiv:2402.10329）及其规模化验证 RDT2。

### P1（3–12 个月）：自研头戴设备 v1（EVT→DVT→PVT）

对标 Aria Gen 2（4 SLAM + 1 RGB + 2 眼动、双 IMU、7 麦、75g、6–8h）但做**任务采集特化**——砍掉研究向传感器，强化手部覆盖与量产成本：

| 子系统 | 规格 | 设计理由 |
|---|---|---|
| 主 RGB 相机 | ≥120° DFOV，1440p60（或 4K30），EIS，**俯角 15–25°** | 操作区域（胸前 30–60cm）必须常驻画面；帧率优先于分辨率（动作恢复需要时间分辨率） |
| 双侧 SLAM 相机 | 灰度全局快门鱼眼 ×2，60fps | VIO 位姿（导航数据轨）+ 手部离开主画面时的补盲 |
| IMU | ×2，≥200 Hz | 头部运动/VIO/防抖；双 IMU 互校 |
| 麦克风阵列 | 4–7 麦 + 骨传导/接触麦 | 任务上下文、Creator 语音备注（"我现在开始洗碗"= 免费弱标注） |
| 可选（P2 再议） | ToF 深度、眼动 | 眼动是注意力监督信号（Aria 已验证）但成本/标定复杂，量产版再上 |
| SoC | 高通 AR1 / RK3588 级 | 只做编码+预检+脱敏，**不做重推理** |
| 存储 | 256GB，环形缓冲，断电安全落盘 | 一个班次不回传也不丢 |
| 编码 | h265 硬编双码率（存档流 + 320p 预览流） | 预览流供 App 即时质检与云端快速筛查 |
| 电池 | ≥4h 连续录制，磁吸充电/可换电 | 对标班次时长 |
| 隐私硬件 | **硬连线录制指示灯**（软件不可关）+ 物理停录开关 | 合规底线，抄 Aria |
| 连接 | WiFi 6 + BLE（App 配对）+ USB-C | 回坞/回家 WiFi 批量上传（复刻 Figure 03 店转发模式） |
| 时钟 | 单调时钟 + NTP 校准，全流统一 ns 时间戳 + 出厂标定文件随数据走 | **多流时间对齐是数据可用性的命门** |

BOM 粗估 $150–300（对标 Quest 3 的 $500 有优势；设备可押金制发放）。固件：嵌入式 Linux，落盘格式即 fdp 的 MCAP schema（分段、含标定/固件版本/传感器健康元数据）。

### P2（12 个月+）：眼镜形态量产版

减重到 <100g、全天佩戴、加眼动。前提：P1 数据已证明训练价值。

## 2. 采集端（Creator 用户侧）

**App 核心回路：领任务 → 录制 → 即时预检 → 上传 → 计酬**

- **任务市场**：任务不是 Creator 随便拍——由策展层的"再平衡"服务**反向生成任务配额**（缺什么任务/物体/环境就下发什么），带任务模板（起止口令、必拍要素）。这是把 Index"重平衡"从被动筛选变成主动指挥采集。
- **录制引导与即时预检**：端上轻量模型实时提示——曝光/模糊/剧烈抖动/**手部可见率过低**；不合格当场重录，不浪费上传。
- **上传管理**：仅 WiFi、分片断点续传、预览流先行（云端预筛不过则不传存档流——省 90% 无效带宽）。
- **计酬与信誉**：按"通过策展的分钟数"计酬；信誉分级（高信誉抽检率低、单价高；新账户全量审）；双边市场模式（预约 Creator 上门干活）后置到平台成熟后。
- **端上合规**：录制指示灯 + App 强提示；Creator 协议（数据用途/授权链）；可选端上旁观者人脸模糊；未成年人排除；分区域合规开关（GDPR 被遗忘权 → 数据删除传导，见 §3）。

## 3. 数据平台

```
设备/App ──分片上传──► Ingest 网关（校验:哈希/schema/标定/内容安全）
                          │
                 对象存储三区：raw / curated / training
                          │  （metadata: Postgres；向量库: embedding 去重与检索；队列驱动策展 DAG）
                          ▼
      ┌──────────── 策展 DAG（五阶段，对标 Index）────────────┐
      │ 1 自动质量门  技术(分辨率/fps/时长/传感器完整性)          │
      │              → 视觉(清晰/曝光/抖动/手部可见率)           │
      │              → 语义(VLM: 是否目标任务/摆拍检测)          │
      │ 2 反欺诈     设备指纹/时空一致性/跨账户重复 + 人工审核台   │
      │ 3 去重       视频 embedding 相似度阈值(同人+跨人)        │
      │ 4 再平衡     任务/物体/环境聚类统计 → 多样性 KPI          │
      │              → 反向生成任务配额 → 下发 App              │
      │ 5 分层标注   VLM caption(任务/子任务/操作三级) + 切分      │
      └────────────────────┬────────────────────────────────┘
                           ▼
              数据处理（伪标签工厂，见 §4） ──► LeRobotDataset v3 训练分片
```

- **多样性 KPI** 直接对标 Index 公开口径：每 1,000 小时 ≥370 任务 / ≥1,100 物体 / ≥110 环境，做成周报仪表盘。
- **数据治理**：数据集版本化（快照 tag + lineage 追踪：每个训练分片可回溯到原始上传与策展决策）；删除请求全链路传导（raw→curated→training→已训模型记录在案）。
- 通过率漏斗（上传→门1→…→训练集）是平台第一运营指标。

## 4. 数据处理（清洗之后：伪标签工厂）

human 轨没有动作真值，监督信号靠算法恢复（配方全部来自已验证开源工作，见 architecture.md §2.2/§6）：

1. **相机位姿**：VIO/SLAM（双侧灰度相机 + IMU）→ SE(3) 头部轨迹 → 导航数据（SE(2) 速度指令，Go-Big 路线）
2. **手部姿态**：21 关键点/帧 → EE 位姿 + 夹爪开度；Savitzky-Golay 平滑位置/宽度 + 高斯加权 SLERP 平滑姿态（Ego2Robot 配方，×9.5 数据放大先例）
3. **中间表征**：光流（潜动作模型不可靠：LAPA 0.14 vs 光流路线 SOF 0.69）、单目深度
4. **重定向**：人手 → 目标机器人形态（逐形态 IK + FK 感知监督保持腕/指尖任务空间几何，PrimeU 配方）
5. **QC 三级**：L1 运动学过滤（IK 失败/自碰撞/离群）→ L2 统计轨迹过滤 → L3 VLM 语义审计
6. 产物落 LeRobotDataset v3（分层采样率 schema，`track=human`，伪标签带质量分）

## 5. 训练集成

| 用途 | 配方 | 依据 |
|---|---|---|
| VLA 共预训练 | 与真机数据 **1:1 混合**进动作专家预训练 | Ego2Robot：62.2%→68.1%，OOD 一致提升 |
| 导航策略 | 纯人类视频端到端（图像+语言→SE(2) 速度） | Go-Big 零机器人数据先例 |
| S2/大脑 SFT | 分层 caption 做任务规划/场景理解语料 | Helix 事后反推式标注同路线 |
| 世界模型 | 视频预测预训练（可选，长线） | 数据金字塔中层通用用法 |

训练侧用 StreamingLeRobotDataset 流式喂数据；**数据配比消融是管线内建能力**（按小时/任务/环境/采集方式切子集自动跑缩放曲线），复刻 Figure 的 10/20/40/60h 决策法，并按 GEN-0 的 L(D)=(D_c/D)^α 幂律拟合边际收益。

**演示库（GEN-1.5 后新增的数据消费形态）**：策展产物除训练分片外，还输出**可检索演示库**——按任务 embedding 检索、3–12 秒干净切片、可组合。物理提示（in-context 演示）已被 GEN-1.5 证明是涌现能力（1 条演示零梯度 59%，5 分钟数据 10 步微调 83%），策展的子任务切分与分层标注天然支撑这个形态，一份投入两份回报。

## 6. 验证体系（三层）

- **数据侧**：多样性 KPI 周报；通过率漏斗；伪标签质量抽检（人工 + VLM 双盲，抽检率随 Creator 信誉浮动）；缩放曲线（新增 N 小时对下游指标的边际收益 → 指挥采集预算）。
- **模型侧**：仿真基准（LIBERO/RoboTwin 类 + Isaac Lab Arena 回归）；真机 A/B（有无 human 轨数据的对照微调）；OOD 泛化专项（背景/光照/物体扰动轴向拆解）；**少样本适应基准**（1 条演示零梯度 / 5 分钟数据 10 步微调的成功率，GEN-1.5 口径）——少样本下单条演示质量直接决定成败，是比全量微调更灵敏的数据质量探针。
- **平台侧**：欺诈拦截率与漏检率；**每可用训练小时全成本**（目标 < 遥操作的 1/5，PrimeU 实测人类视频吞吐为遥操作 4.8–7.2×）；Creator 留存与 NPS。
- **诚实性协议**：所有对外/对内能力宣称必须附可复现日志与干预率记录（吸取 Figure/BMW 争议教训）。

## 7. 里程碑

| 阶段 | 时间 | 交付 | 关键验证 |
|---|---|---|---|
| **M0** | 0–3 月 | 手机 P0 方案 + 平台 MVP（ingest/质量门/人工审核台）+ 伪标签管线 v0 | 100 小时可用数据；伪标签能训出仿真可见收益 |
| **M1** | 3–6 月 | 设备 EVT（10–50 台）+ 五阶段策展全自动化 + 任务配额闭环 | 每可用小时成本 < 遥操作 1/3；多样性 KPI 达标 |
| **M2** | 6–12 月 | DVT→PVT（500+ 台）+ 千人 Creator 网络 + 训练闭环 A/B | 真机 A/B 证明 human 轨数据显著收益；欺诈率 <1% |

## 8. 核心风险与对策

1. **无动作标签的监督上限**：伪标签质量决定一切 → 显式中间表征（光流/重定向）优先于潜动作；M0 就要跑通"伪标签→仿真收益"最小验证，不见收益不投硬件。
2. **触觉/力学缺失**：human 轨天然无力觉 → 接受其定位为"预训练规模腿"，接触密集能力靠 robot 轨封顶；P2 可评估腕带 EMG/音频振动等廉价代理信号（未验证，标注为探索项）。
3. **隐私合规**：进家庭采集是法律雷区 → 硬件指示灯 + 端上脱敏 + 分区域合规 + 删除传导，法务先行于规模化。
4. **单位经济**：设备补贴 + 计酬 + 云成本 vs 数据价值 → 每季度重算"每可用小时全成本"，与遥操作/仿真替代路线对比决定投入配比。
