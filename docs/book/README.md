# 具身数据管线：从采集到回流

> 专题书 · 2026-11-20 · 基于本仓库截至 2026-11-18 的全部设计与调研文档整理

这本书把仓库里分散在五十多份设计、规范与调研文档中的内容，按"一条数据从被录下来到让机器人变好"的顺序重新讲一遍。它回答三类问题：

- **为什么**：具身数据和互联网数据、自动驾驶数据有什么不同，瓶颈到底在哪；
- **怎么做**：每一层（采集、入湖、质检、标注、合成、挖掘、数据集、训练消费、评测回流）做什么、产出什么、按什么规则；
- **凭什么**：每个决策依据哪家的做法、证据可信度如何、哪些仍是未决项。

本书不是新的规范。规范以各层原文为准（每章末尾列出），书里出现的阈值、字段与流程如与原文冲突，以原文为准，并请把冲突登记到 [governance.md](../governance.md)。

## 本书约定

- **数字的可信度**：引用他家的数字一律标来源属性。"官方"指公司一手材料，"论文"指公开论文，"第三方"指媒体或分析机构，**⚠️ 自报**指公司未经独立验证的性能、规模、成本数字。依赖自报数字的设计决策都已登记在 [governance.md](../governance.md) 的 D 表。
- **三套里程碑前缀不混用**：M1/M2/M3 是工程里程碑（按管线层）；H0/H1/H2 是 Index 复刻的硬件与平台时间线；P0/P1/P2 是采集硬件成熟度。对外产品线用 PL1–PL5。
- **编号引用**：U-xx 为未决决策、R-xx 为风险、D-xx 为自报数字登记，均见 [governance.md](../governance.md)。
