# 叠衣与晾衣：大脑 v2、动作原语与跨品类泛化计划

> 2026-09-20。对应 [laundry-two-plans-brief.md](laundry-two-plans-brief.md) 交付二的步骤 A6（叠）、A7（晾）、A8（收纳）、A9（VLM 大脑 v2）。与交付一的 [laundry-sorting-brain-plan.md](laundry-sorting-brain-plan.md) 并列；分类大脑输出的 `garment_type` 与 `no_tumble_dry` 标记是本计划的输入。**样本量、准确率与周期为设计目标或我方估算 ⚠️；引用的他家结论均为公司自报 ⚠️。** 周次从交付二开工起算（原版第 6 个月、加速版第 3 个月）。

## 0. 结论先说

1. 交付一的任务与品类基本无关；**交付二才真正依赖品类**，泛化是这一阶段的主问题，也是决定要不要启动自有预训练（方案 B）的依据。
2. 解法是**分工**：品类知识放在 VLM 大脑里（用语言写成折法 / 晾法 SOP），动作能力放在小脑里（与品类无关的语言条件原语）。新增一个品类 = 写一条 SOP + 补少量演示，不重训整个模型。
3. 所有衣物先**规范化**到同一个中间状态（摊平、朝向一致、关键点可见），把泛化难度集中到"摊平"这一个与品类基本无关的技能上。
4. 数据按**结构类**覆盖，不按款式；每类 20–30 件不同实物轮换，单件演示数设上限。
5. 验收看**泛化差距**（域内减域外），并用"留一类不训"测试；叠毛巾探针扩成"训两类、测第三类"，作为方案 B 的启动判据。
6. 商业上用**品类白名单**兜底：白名单外进人工筐，按试点订单件数统计的占比顺序扩展。

## 1. 分工：大脑管"折成什么样"，小脑管"怎么动"

| | VLM 大脑 v2（~1 Hz，按步触发） | 动作模型（≥10 Hz） |
|---|---|---|
| 知道什么 | 品类、正反、朝向、当前步骤、折法 / 晾法 SOP、质检标准 | 怎么抓角、拖平、沿线折、翻面、推齐、穿衣架、挂杆 |
| 输入 | 头部画面 + 腕部近拍 + 上一步成败 | 头 / 腕画面 + 本体感知 + 一句子任务指令 |
| 输出 | 下一句子任务指令（含目标关键点的自然语言描述）；成败判别；重试或转人工 | 双臂末端增量位姿 + 夹爪开合 |
| 随品类变化 | **是**：每个品类一条 SOP（文本，版本化） | **否**：原语集合对所有品类共用 |
| 新增品类的成本 | 写 SOP + 几十条质检标注 | 每个原语补 ≤2 h 该结构类的演示 |

SOP 示例（短袖 T 恤）：`摊平(正面朝下) → 抓(左袖口+左下摆) → 折到(中线) → 抓(右袖口+右下摆) → 折到(中线) → 抓(下摆两角) → 折到(领口) → 推齐 → 质检`。SOP 存 `configs/laundry/sop/<garment_type>_v1.yaml`，改动即新版本，版本号进 lineage。

### 1.1 共用原语集（v1）

| 原语 | 语言条件 | 适用 |
|---|---|---|
| 摊平 | 目标朝向 | 全部品类；**泛化的承重技能** |
| 抓关键点 | 关键点名（角、袖口、裤腰、下摆、领口、肩线） | 全部 |
| 沿线对折 | 折线位置（中线、三分线、到某关键点） | 全部 |
| 翻面 / 旋转 | 目标朝向 | 全部 |
| 推齐 / 压平 | — | 全部 |
| 移入收纳位 | 筐 / 货架层 / 客户袋 | 全部 |
| 穿衣架 | 衣架类型 | 上衣类、下装夹式 |
| 挂杆 / 取杆 | 杆位 | 晾 |
| 夹子固定 | 夹点 | 小件、下装 |

原语之间的状态由大脑判定；任何一步失败，默认回到"摊平"重来，这是规范化设计的另一个好处。

## 2. 规范化：把差异消在第一步

- 目标状态：单件、平铺在台面、指定面朝上、关键点在相机视野内。
- 摊平的子策略与品类无关：提起最高点 → 甩落或拖拽 → 抓对角拉展 → 视觉检查褶皱与遮挡。上肢目前是位控，"甩"动作幅度受限，以拖拽与对角拉展为主；力控上线后再评估（`controller_version` 隔离）。
- 关键点由大脑层给出语言描述，动作模型在画面里自己落点；不单独训练关键点检测器，除非第 4 周检查点显示落点误差是主要失败原因。
- 晾挂同理：先规范化到"肩线水平、领口朝上"，再穿衣架。

## 3. 数据：按结构类覆盖

### 3.1 五个结构类

| 结构类 | 代表品类 | 实物数 | 变化轴 |
|---|---|---|---|
| 矩形类 | 毛巾、浴巾、枕套、床单 | 25 | 尺寸 ×3、厚薄 ×2 |
| 上衣类 | 短袖、长袖、衬衫（带扣）、卫衣 | 30 | 袖长、领型、面料软硬、尺码 |
| 下装类 | 长裤、短裤、牛仔、裙 | 25 | 长度、腰型、面料 |
| 小件 | 袜（配对）、内裤 | 20 | 尺寸、弹性 |
| 特殊件 | 连帽、连衣裙、带衬垫内衣、针织 | 20 | 先只进人工筐，第二批再做 |

共约 120 件，全部编号；每件的尺寸、面料、重量登记进衣物档案，采集与评测日志里引用编号。

### 3.2 采集纪律

- 每个原语 × 每个结构类 ≤10 h 遥操作（Dyna 口径）；交付二合计 100–160 h（汇报稿 §6）。
- **轮换**：同一件衣物连续演示不超过 5 次；单件演示数不超过该原语总数的 5%。依据：重复同一成功动作"再采也没用"（Skild）、高质量子采样优于均匀采样（Sunday，D-25），均为自报 ⚠️。
- 恢复数据单独采：故意从"折歪""滑落""抓到两层"的状态开始，演示如何回到摊平。
- 每个结构类留出 5 件实物只做评测，永不进训练。

### 3.3 不动权重的适应层

每个品类在演示库里存 3–5 条 3–12 秒片段；若选定基座支持上下文演示，推理时作为提示（training-pipeline §1.2-6 已预留接口）。是否有效以实测为准，不作为交付依赖。

## 4. 训练与排期（交付二开工起算）

| 周 | 内容 | 判据 |
|---|---|---|
| 1–3 | **泛化探针**（原"叠毛巾探针"扩充）：只用矩形类 + 上衣类各 ≤10 h 训练；测下装类（完全没训过）与各类留出实物 | 见 §5.2；结果同时决定是否启动方案 B |
| 2–6 | 共用原语 v1：摊平、抓关键点、沿线对折、推齐；三个结构类 | 留出实物上单原语成功率 ≥85% |
| 3–8 | 大脑 v2：品类 → SOP 选择、步骤成败判别、折叠质检判别（几千条标注；标注流程沿用分类大脑 §3.2） | 步骤判别与人工一致率 ≥90%；质检判别 ≥90% |
| 5–10 | 晾挂原语：穿衣架、挂杆、夹子；输入来自分类阶段的 `no_tumble_dry` 标记 | 单件晾挂成功率 ≥85%，掉落为零容忍项 |
| 8–12 | 小件（袜配对）与收纳；全流程串联 | 六任务连续运行 ≥8 h |
| 10–16 | 现场试运行；人工筐与客户退回件每周回流；T0（SOP 与提示库）当天可改，T1（干预段后训练）每两周一次 | 交付二验收（§5.1） |

## 5. 评测与验收

### 5.1 指标

| 指标 | 定义 | 交付二验收 |
|---|---|---|
| 折叠质检通过率 | 按客户口径（尺寸一致、边缘对齐、无外露袖 / 裤腿） | 白名单品类 ≥90% |
| 泛化差距 | 训练用过的实物上的通过率 − 留出实物上的通过率 | ≤10 个点 |
| 跨类差距 | 白名单内各结构类通过率的最大差 | ≤15 个点 |
| 每百件干预 | 人工介入次数 | ≤10 |
| 晾挂成功率 / 掉落 | 单件挂稳；掉落 | ≥90% / 0 |
| 节拍 | 件 / 小时 | 第 4 周实测后定；参照 Dyna 固定双臂自报 95–100 条 / 小时 ⚠️，人形预期更低 |

### 5.2 泛化探针的判据（同时是方案 B 的启动判据）

| 结果 | 读法 | 动作 |
|---|---|---|
| 留出实物通过率 ≥60%，且没训过的下装类 ≥30% | 外部基座的布料先验够用 | 继续方案 A；不启动 B |
| 留出实物 ≥60%，但下装类 <30% | 同类内能泛化、跨类不行 | 继续 A，按结构类逐类补数据；B 暂缓，第 8 周复评 |
| 留出实物 <60% | 连同类新实物都不行，先验不足 | 启动方案 B（或先试 [dyna-parity-fast-track.md](dyna-parity-fast-track.md) §2.2 的低成本杠杆：在后训练里混入人类叠衣视频的伪动作数据） |

依据：Dyna 报告同样 ≤10 h 后训练下真机表现随预训练规模 20% → 53%，跨具身迁移在 1 万 – 10 万小时之间涌现；Sunday 报告泛化差距随预训练规模 82 → 0、单条示例可教会可泛化折法（均为自报 ⚠️，D-22、D-25）。

## 6. 品类白名单与扩展顺序

- 白名单 v1（建议）：毛巾类、短袖与长袖 T 恤、长裤。其余进人工筐，不计入验收指标。
- 扩展顺序由试点洗衣房的订单件数占比决定；**当前没有这份统计 ⚠️，交付一期间取得。**
- 每新增一个品类：归入结构类 → 写 SOP → 采该类 ≤2 h / 原语的演示 → 跑留一类与留出实物测试 → 泛化差距 ≤10 点 → 进白名单。目标是第三个品类之后，新增成本降到"SOP + 零到几十条演示"。

## 7. 风险

| 风险 | 对策 |
|---|---|
| 摊平在位控手臂上效率低（不能大幅甩动） | 以拖拽与对角拉展为主；节拍目标实测后定；力控上线后重评 |
| 关键点落点不准 | 第 4 周检查失败归因；必要时加轻量关键点模块，只输出给大脑层做描述校正 |
| 带扣、拉链、连帽等结构件 | 归入特殊件，第二批；白名单外走人工 |
| 袜子配对 | 识别问题多于操作问题，交给大脑层按颜色 / 纹理 / 长度匹配；配不上进人工筐 |
| 评测衣物磨损变形 | 评测实物定期更换并登记；新旧实物结果分开报 |
| 外部基座先验不足 | §5.2 探针第 3 周出结论，不拖到验收才发现 |
