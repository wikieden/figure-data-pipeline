# 洗衣房任务两套方案汇报稿：后训练方案 vs 预训练方案

> 2026-09-20。汇报对象：管理层。范围：六项任务、分两次交付——**交付一：脏衣服分类 → 洗衣服 → 烘干；交付二：晾衣服 → 叠衣服 → 收纳**（2026-09-20 三版按负责人确定的顺序重排）；本体为自有的 6 台自研轮式人形（二指力控夹爪、腕部 RealSense D405 × 2、头部 D457、机载 Jetson Thor、上肢位控 ≥200 Hz、升降腰、VR 遥操作已就绪）。设计依据与逐项推算见 [dyna-replica-plan.md](dyna-replica-plan.md)（方案 A = 其 §12；方案 B = 其 §0–§8 的洗衣收敛版）。**全部金额、算力、周期为我方估算 ⚠️，用于排序与止损，不是报价；引用的他家数字均为公司自报 ⚠️（governance D-22、D-26）。** **币种为美元；人力按台湾地区全成本估算（工程师 $56–94k / 人年，见 §4），原始估算以新台币做出，按 32 新台币 / 美元换算（2026-09-21 七版统一改为美元；八版增加方案 A 精简版 §8.3，作为建议主线）。** 2026-09-20 二版：成本改为按步骤 × 按类型拆分；三版：任务改为六项、两次交付；四版：增加团队放在中国大陆的成本对照（§4.5）；五版：增加交付一压缩到 3 个月的加速版（§8.1）；六版：按 [plans-review-hard-points.md](plans-review-hard-points.md) 的评审补入难点对策（§7、§8.1、§8.2）。

## 1. 结论（先说）

1. **建议立即批准方案 A 的交付一（分类 → 洗 → 烘，6 个月、5–6 人、约 $266–509k）**，第 3 个月设过程门，第 6 个月在洗衣房现场验收。
2. 交付一的三项任务是"从衣堆抓单件、开关机器门、整把装卸"，对布料精细操作要求低，主要靠 VLM 大脑的识别与编排 + 后训练的抓取放置。**这部分用方案 A（外取基座 + 后训练）把握较大，不需要自有预训练。**
3. 方案 B（自有预训练）真正起作用的地方是交付二里的叠和晾——布料精细操作与新面料泛化。所以 **B 的决策点放在第 6–7 个月**：交付一验收后，用 2–3 周的"叠毛巾探针"测外部基座对布料的先验够不够，不够再启动 B。
4. 方案 B 不是 A 的替代，而是 A 的超集：多加一段自有预训练，其余相同。A 的设备、数据、评测集、管线全部复用，没有沉没成本。
5. 为保住 B 这个选项，A 执行期间以最低档持续采集洗衣人类视频（每月 $3–6k）。（精简版 §8.3 不采，代价见该节。）

6. **2026-09-21 增补：方案 A 给出精简版（§8.3）——6 个月、4 名工程师、$176–334k，约为原版的三分之一强。** 负责人判断原版时间与成本偏多；逐项复核后，原版里确有约六成属于"稳妥余量与可后置项"，精简版把它们去掉并写明代价。建议以精简版为主线，原版（§4）保留作保守口径的上限。

## 2. 两套方案是什么

| | **方案 A：后训练 + VLM 大脑** | **方案 B：自有预训练 + 后训练 + VLM 大脑** |
|---|---|---|
| 一句话 | 拿开放权重的机器人基座模型，用我们自己的洗衣遥操作数据做后训练，上面叠一个 VLM 做任务编排 | 先用几万小时人类洗衣 / 家务第一视角视频，训一个自己的"世界-动作模型"基座（Dyna DYNA-2 的做法），再做与 A 相同的后训练 |
| 基座从哪来 | 外取：π0.5 为主，GR00T N1.7 作对照（许可逐项核查，U-11 / U-29） | 自训：开放权重视频扩散骨干 + 自研动作分支，2B → 5B |
| 大脑（~1 Hz） | 开放权重 VLM 8B 级：先提示词 + SOP 状态机，试点前用几千条洗衣标注微调 | 同 A |
| 小脑（≥10 Hz） | 后训练的 VLA，输出双臂末端增量位姿 + 夹爪，经 IK 转关节位置指令 | 后训练的自有基座，接口同 A |
| 我们拥有什么 | 对齐层数据、评测集、数据管线、VLM 大脑的洗衣 SOP | A 的全部 + 预训练基座 + 人类视频语料 |
| 对标 | 仓库默认路线 Stage A；形态参照 Harness VLA（论文自报 ⚠️） | Dyna DYNA-2：人类视频预训练 + 每任务 ≤10 h 后训练 |

### 4.5 团队放在中国大陆的成本对照（2026-09-20）

同一套步骤与人月，只换人力单价和受地点影响的非人力项。单位：**千美元（$k）**；原始估算以人民币 / 新台币做出，按 7.1 人民币 / 美元、32 新台币 / 美元换算。大陆人力全成本（含五险一金，我方估算 ⚠️，未取得薪资调查来源）：一线城市具身智能算法 / 机器人工程师 $85–141k / 人年，新一线 $56–99k / 人年；遥操作员 $11–21k；标注员 $8–17k；数据运营 $25–56k。非人力项的调整：环境件 ×0.7–0.8、现场与合规 ×0.6–0.8、人类视频采购 ×0.5–0.6（大陆众包单价更低）、伪动作算力 ×0.8–1.0、训练算力 ×1.0–1.3（高端 GPU 在大陆供给受限，按等效 H100·h 计价偏高）。

**读法**：搬到大陆**省不了多少钱，放在一线城市反而更贵**。原因是这个项目六到七成是工程人力，而具身智能方向的算法工程师在大陆一线城市的全成本高于台湾同级；便宜的是遥操作员、标注员、环境件和人类视频采购，但这些在方案 A 里合计不到三成。新一线城市能省一成左右；方案 B 因为人类视频占比高，在大陆新一线做同样约省一成，一线城市的涨幅也比方案 A 小。

**比成本更要紧的五件事**（都需要在决定前核实，我没有核查过，⚠️）：

| 事项 | 影响 |
|---|---|
| 6 台机器人与 Jetson Thor 的跨境 | 整机进出口、暂准进口手续与周期；Thor 属较新一代 GPU 模组，对大陆的出口管制状态须向供应商确认 |
| 训练算力 | 大陆难以按挂牌价取得 H100 级算力；方案 A 微调量小，可用 H20 / 4090 级或国产卡，影响有限；方案 B 的 8–12 万 H100·h 受影响大，可能需要在境外云训练 |
| 基座模型与许可 | π0.5、GR00T N1.7 等美国来源权重的许可条款含出口合规约束；大陆团队可改用本土开放权重基座（Qwen 系 VLM 无障碍），VLA 基座需另行选型并重新核查许可 |
| 数据跨境 | 试点洗衣房若在台湾，现场视频（含旁观者）传到大陆训练，两边的个人资料法规都要过；反过来在大陆采集、回传台湾同理。混合方案最受这条约束 |
| 人才供给 | 大陆具身智能人才池明显更大、招聘更快，这是搬过去的真正理由；不是成本 |

**建议**：若目的是省钱，不值得搬；若目的是招得到人、招得快，首选"工程在大陆新一线 + 遥操作与试点留在台湾"的混合方案，成本与全在台湾持平，但要先解决数据跨境与基座许可两件事。交付一的数据量小（80–135 h 遥操作），可以先按"数据不出境、在台湾本地训练，大陆工程师远程开发"起步。

### 8.1 加速版：交付一压缩到 3 个月（2026-09-20，负责人提出）

**3 个月成立的十个前提**（后三条为 2026-09-20 评审补入）（任一不成立，交付一 a 顺延）：

1. 9 名工程师第 0 天到岗。招聘时间不在 3 个月之内。
2. 第 1 周内订到可联网控制的洗衣机与烘干机；第 1 个月内签下试点洗衣房。
