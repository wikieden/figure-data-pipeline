# 洗衣房任务两套方案汇报稿：后训练方案 vs 预训练方案

> 2026-09-20。汇报对象：管理层。范围：洗衣服、叠衣服、晾衣服、摆放衣服四项任务；本体为自有的 6 台自研轮式人形（二指力控夹爪、腕部 RealSense D405 × 2、头部 D457、机载 Jetson Thor、上肢位控 ≥200 Hz、升降腰、VR 遥操作已就绪）。设计依据与逐项推算见 [dyna-replica-plan.md](dyna-replica-plan.md)（方案 A = 其 §12；方案 B = 其 §0–§8 的洗衣收敛版）。**全部金额、算力、周期为我方估算 ⚠️，用于排序与止损，不是报价；引用的他家数字均为公司自报 ⚠️（governance D-22、D-26）。** 汇率按 7.1 元 / 美元；人力按国内全成本 60–100 万元 / 人年。

## 1. 结论（先说）

1. **建议立即批准方案 A 的第一阶段（3 个月、4 人、约 70–135 万元）**，第 3 个月用一道可测的门决定下一步。
2. 方案 B 不是 A 的替代，而是 **A 的超集**：B 在 A 之前加一段自有预训练，之后的后训练、VLM 大脑、试点与 A 完全相同。所以真正的决策是"要不要、什么时候加那段预训练"，不是二选一。
3. 第 3 个月的门若卡在**布料泛化**（换一批衣物、换一个站点就掉成功率），再启动 B；届时 A 的设备、遥操作数据、评测集、管线全部复用，没有沉没成本。
4. 为了保住 B 这个选项，A 执行期间以最低档持续采集洗衣人类视频（每月 2–4 万元）。

## 2. 两套方案是什么

| | **方案 A：后训练 + VLM 大脑** | **方案 B：自有预训练 + 后训练 + VLM 大脑** |
|---|---|---|
| 一句话 | 拿开放权重的机器人基座模型，用我们自己的洗衣遥操作数据做后训练，上面叠一个 VLM 做任务编排 | 先用几万小时人类洗衣 / 家务第一视角视频，训一个自己的"世界-动作模型"基座（Dyna DYNA-2 的做法），再做与 A 相同的后训练 |
| 基座从哪来 | 外取：π0.5 为主，GR00T N1.7 作对照（许可逐项核查，U-11 / U-29） | 自训：开放权重视频扩散骨干 + 自研动作分支，2B → 5B |
| 大脑（~1 Hz） | 开放权重 VLM 8B 级：先提示词 + SOP 状态机，试点前用几千条洗衣标注微调 | 同 A |
| 小脑（≥10 Hz） | 后训练的 VLA，输出双臂末端增量位姿 + 夹爪，经 IK 转关节位置指令 | 后训练的自有基座，接口同 A |
| 我们拥有什么 | 对齐层数据、评测集、数据管线、VLM 大脑的洗衣 SOP | A 的全部 + 预训练基座 + 人类视频语料 |
| 对标 | 仓库默认路线 Stage A；形态参照 Harness VLA（论文自报 ⚠️） | Dyna DYNA-2：人类视频预训练 + 每任务 ≤10 h 后训练 |

## 3. 效果预期

没有任何一家公开过可直接套用的洗衣成功率曲线，下表是**验收目标**与**判断依据**，不是承诺。

| | 方案 A | 方案 B |
|---|---|---|
| 第 3 个月 | 叠毛巾 + T 恤：质检通过率 ≥80%，每百条干预 ≤10 次；大脑层成败判别与人工一致率 ≥90% | 管线打通，2B 模型首轮对照跑完，单机推理 ≥10 Hz；**此时还没有真机结果** |
| 第 6 个月 | 晾、洗两项子技能上线 | 验证核心主张：联合预测视频 + 动作优于只预测动作（≥80% 留出任务）；叠 + 摆放真机后训练结果 |
| 第 9 个月 | 四任务全流程在试点洗衣房连续运行 ≥8 h，客户质检通过率 ≥90% | — |
| 第 14 个月 | —（已进入扩站） | 同 A 第 9 个月的指标，外加"未见过的衣物类型 / 新站点零调整"的泛化指标 |
| 能力上限 | 由外部基座决定。见过的衣物类型、单一站点预期可达标；湿衣、新面料、新站点是最可能卡住的地方 | 预期泛化更好。依据：Dyna 自报同样 ≤10 h 后训练，真机表现随预训练规模 20% → 53%，客户现场质检 46% → 87%，差距来自预训练而非后训练 ⚠️ |
| 节拍 | Dyna 固定双臂自报 95–100 条 / 小时 ⚠️；人形双臂预期更低，目标待第 3 个月实测后定 | 同 A |
| 主要不确定性 | 外部基座对布料的先验够不够 | Dyna 的主张无第三方复现；关键参数（骨干、参数量、算力）均未披露，全为我方估算 |

|---|---|---|

| 训练算力 | 约 1–2.5 万 H100·h（$25–70k） | 约 8–12 万 H100·h（$170–290k），另含 A 的部分 |

## 5. 训练流程

| 步骤 | 方案 A | 方案 B |
|---|---|---|
| ① 预训练 | 无 | 人类视频 1 万 h（其中洗衣 ≥3 千 h）→ 3–5 万 h（洗衣过半）；从视频提取腕位姿 + 拇指-食指开合度作"伪动作"；流匹配联合预测未来视频与动作；2B → 5B；嵌套数据子集 × 两种配方对照，得到自家缩放曲线 |
| ② 后训练 | 四任务拆 15–20 个子技能，每个 ≤10 h 遥操作；π0.5 与对照基座同数据同步数各跑一轮后定稿 | 相同，换成自有基座 |
| ③ VLM 大脑 | 提示词 + SOP 状态机 → 几千条标注微调；判成败用头部 RGB + 腕部深度 + 夹持力 | 同 A |
| ④ 持续升级 | T0 提示库 / 规则（当天可回滚）→ T1 干预段后训练（周级）→ T2 真机 RL（月级，可选） | 同 A，另加 T3：站点数据回灌基座（季度级，仅当缩放消融为正） |
| ⑤ 评测 | 评测机专用、评测衣物不进训练；每个 checkpoint 盲测；跨机单列；序贯检验 | 同 A，另加留出机器人数据上的零样本离线评测 |

## 8. 三条路径与建议

| 路径 | 做法 | 9 个月时 | 14–17 个月时 | 总投入（含人力） |
|---|---|---|---|---|
| ① 只做 A | — | 试点运行 | 扩站 | 390–750 万元 |
| ② **先 A，门后再定 B（建议）** | 第 3 个月的门不过才启动 B | 试点运行或 B 第一阶段进行中 | B 完成（最晚第 17 个月） | 390–750 万元；启动 B 则至 1,140–1,880 万元 |
| ③ A、B 同时起步 | 第 0 天并行 | A 试点运行 + B 核心主张已验证 | B 完成（第 14 个月） | 1,140–1,880 万元 |

**请领导决策的三件事**：① 批准方案 A 第一阶段（3 个月、4 人、70–135 万元）；② 批准保选项的人类视频最低档采集（每月 2–4 万元）；③ 确认第 3 个月的门（叠毛巾 + T 恤质检通过率 ≥80%、每百条干预 ≤10 次）作为是否启动 B 的依据。

## 9. 口径说明

- 金额、算力、人月均为我方估算 ⚠️：Dyna 未披露骨干、参数量、算力等关键参数（governance R-21）；硬件环境件未询价；算力按公有云挂牌价 $2–2.5 / H100·h，自有集群或长约可再降 30–50%。
- Dyna 的 20% → 53%、46% → 87%、95–100 条 / 小时均为公司自报 ⚠️，无第三方复现（D-22、D-26）；一手原文归档于 `sources/dyna/`。
- 相机规格、Thor 同机推理能力为经验判断，列入第 1 个月实测项。
